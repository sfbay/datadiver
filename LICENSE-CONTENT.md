# Content & Data License

DataDiver uses a **two-license split**, the convention data-desk newsrooms
use for projects that are part software, part journalism:

- **Software** — all source code in this repository — is licensed under the
  **MIT License** (see [`LICENSE`](./LICENSE)).
- **Editorial content and original derived datasets** — everything below —
  are licensed under the **Creative Commons Attribution 4.0 International
  License (CC BY 4.0)**.

  License deed: <https://creativecommons.org/licenses/by/4.0/>
  Full legal code: <https://creativecommons.org/licenses/by/4.0/legalcode>

## What CC BY 4.0 covers here

The written and curated work product of the project, to the extent it is
original to the project:

- Documentation and editorial prose — the `docs/` directory (including
  `docs/data-insights.md` and the methodology write-ups), the About page
  copy, README narrative, and the published papers under `docs/papers/`.
- Original **derived datasets** the project produced by transforming public
  sources — for example the parsed and reconciled election results, the
  Oakland beat-name editorial synthesis (`src/cities/oakland/beatNames.ts`
  and its evidence JSON), and the normalized boundary GeoJSON generated by
  the `scripts/` build tools.

## What this does NOT cover

- **Underlying public data** belongs to its publishers — DataSF, Oakland
  Open Data (data.oaklandca.gov), the San Francisco Department of Elections,
  Caltrans, and the others listed in the About page's Sources tables — under
  each publisher's own terms. This project claims no ownership of the source
  facts; CC BY 4.0 applies only to the project's original selection,
  arrangement, and synthesis.
- **Share-alike third-party data.** Any derived dataset built from a
  share-alike source carries that source's terms, which override the CC BY
  grant for that dataset. In particular, a layer derived from OpenStreetMap
  (including crowdsourced camera data via DeFlock) is governed by the Open
  Database License (ODbL) — attribution **and** share-alike. None is
  vendored today; this clause is here so a future one inherits the right
  terms by default.
- **Fonts, Mapbox, and other bundled dependencies** are governed by their
  own licenses.

## How to attribute

page or source is appreciated so readers can trace the provenance.
